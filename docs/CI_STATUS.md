# Framework build status

Java build status is consolidated in Jafly. Its single reactor CI validates the parent, BOM, and modules together. A CI badge reports build status, not registry publication or live-provider acceptance.

Former Java source repositories retain their historical runs, branches, tags, and releases. Their per-repository workflow badges no longer describe current Java development after cutover. Use the [Jafly module catalog](https://fireflyframework.github.io/fireflyframework-jafly/modules/) for current source locations and the [CI/CD guide](CI_CD_GUIDE.md) for current workflows.
